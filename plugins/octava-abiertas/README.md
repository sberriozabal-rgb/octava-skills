# octava-abiertas

Plugin con las skills abiertas del catálogo de Sergio Berriozábal Serrano. Hoy contiene una:

- **apertura-cierre-turno** — checklists de apertura, cambio de turno y cierre de un local de
  hostelería, con responsable por puesto, momento exacto y criterio de «hecho», y el parte de
  incidencias que los acompaña.

```
/plugin marketplace add sberriozabal-rgb/octava-skills
/plugin install octava-abiertas@octava
```

El resto del catálogo, con precio y ficha, en el [README del repositorio](../../README.md).
