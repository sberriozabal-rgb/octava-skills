# Skills para Claude · catálogo de Sergio Berriozábal Serrano

Diecisiete skills de oficio para **Claude Code** y cualquier cliente del estándar abierto
[Agent Skills](https://agentskills.io/specification). Cada una hace una cosa concreta con tus
propios datos, dice qué no hace, y se instala copiando una carpeta. Hostelería, cabina de DJ y
B2B. **Una es gratis y se instala desde aquí; las demás se compran.**

## Instala la skill abierta en dos líneas

```
/plugin marketplace add sberriozabal-rgb/octava-skills
/plugin install octava-abiertas@octava
```

Es el checklist de **apertura, cambio y cierre de turno** para hostelería, con responsable por
puesto, momento exacto y criterio de «hecho». Sirve para juzgar cómo trabaja una skill de esta
serie antes de comprar ninguna.

## Lo que ninguna skill promete

Ninguna promete resultados. Cada ficha dice qué hace, con qué datos, para quién no es y qué no
hace. Los casos de prueba son de fabricación; la primera ejecución con datos reales es la tuya.
